# WOA Candidate Image Evaluation Rubric

Evidence gathering, not automated canon certification. For each criterion return PASS / FAIL / UNKNOWN, confidence from 0 to 1, evidence and reference IDs.

| Criterion | Inspect | Blocking |
|---|---|---|
| Reference provenance | Exact approved IDs and hashes | Yes |
| Character identity | Candidate vs bound artwork | Suspected drift blocks for human review |
| Anatomy / form | No unsupported additions or missing features | Yes |
| Character count | Only specified characters | Yes |
| Location continuity | Bound location reference | Yes |
| Props / object state | No unexplained objects or possession | Yes |
| Composition | Requested framing and action | Usually |
| Negative constraints | No prohibited elements | Yes |
| Story beat | Correct approved scene | Yes |
| Technical quality | Crop, resolution, artefacts | Review |

Missing mandatory reference = BLOCKED. Any canon/story FAIL = REVISE or REJECT. UNKNOWN is never PASS. Iterations are bounded; stop after the configured limit. Only the human editor approves canon.

A user correction becomes a new rule only after the human confirms its scope. Record it as a dated decision; do not generalise a one-scene correction into a universal rule.
