# Scene-state ledger

The scene-state ledger records only physical state and actions explicitly supported by the seven published opening scenes. It does not invent scene-to-scene continuity.

## Separation of concerns
- `scene-state-ledger.json`: character physical state, transient actions and unresolved physical continuity.
- `prop-ledger.json`: prop ownership, possession, location and handling.
- `knowledge-ledger.json`: what each character knows, believes or recalls, and what remains author-only.
- Imported scene JSON remains the verbatim source of dialogue and stage directions.

## State rules
1. Unknown is not a blank to fill creatively.
2. A transient action is not a persistent state. Events marked `not_assumed` are not carried forward.
3. A scene participant is not automatically located at a known coordinate or even a known part of a set.
4. Conflicting source descriptions remain visible as unresolved issues.
5. Eric never holds objects; ticket interaction is recorded as body nudging only.
6. No production-ready snapshot is inferred from these source imports. Snapshots remain empty until explicit scene boundaries and state are approved.
