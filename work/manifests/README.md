# Reference Binding Manifests\n\nStore immutable manifests here or in a scene-specific work package. Each manifest binds a scene to exact approved asset IDs and SHA-256 hashes. The scene record's reference_manifest field must point to this file using a repository-relative path. The validator checks scene ID, ready gate, approved asset status, hashes and all required asset IDs. Create a new manifest for each changed reference set; do not overwrite a manifest used by an existing generation attempt.\n
