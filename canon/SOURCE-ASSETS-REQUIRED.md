# Source Assets Required

This repository starts without imported artwork. Do not fill these entries with guesses.

## Required inventory
- [ ] Canonical character artwork for each active character
- [ ] Canonical High Scraparral artwork and other approved locations
- [ ] Approved props / recurring objects requiring continuity
- [ ] Style or composition references explicitly designated as canon
- [ ] Previously approved scene artwork permitted for reuse as reference

## Intake
1. Confirm the user has designated the file canonical or approved for reference.
2. Preserve original bytes; do not crop, compress, retouch or rename in place.
3. Record stable asset ID, original filename, media type, dimensions, SHA-256, source location, approval status and authority.
4. Add the record to canon/artwork-registry.json.
5. Bind by asset ID in scene manifests, never by filename alone.
